Quick Install

Install any MoonBit toolchain version with a single command. Supports latest, nightly, and specific versions.

📌

Project Pinning

Pin a specific toolchain version to your project. moonup automatically switches when you enter the directory.

🔄

Automatic Switching

Shim executables transparently route commands to the correct toolchain. No manual PATH management needed.

🚀

CI Ready

First-class GitHub Actions support with the setup-moonup action. Perfect for reproducible builds.

Quick Start ​

Install moonup with your preferred method:

sh
cargo-binstall moonup
sh
cargo install moonup
sh
brew install chawyehsu/brew/moonup
sh
pixi global install moonup -c chawyehsu -c conda-forge

Then install a MoonBit toolchain:

sh
moonup install latest

That's it! You're ready to start building with MoonBit.
